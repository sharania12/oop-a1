# oop-a1
This project is a text-based, adventure game written in Java. Players navigate through an interactive world, explore rooms, solve puzzles using inventory items and track their progress via a score and text-based map.

### Key Features
**World Exploration:** Move through custom rooms using directions (`move north`, `move south`, etc.) and examine room details with `look` commands.
* **Interactive Map System:** Displays an interactive text-based grid mapping out explored areas as you move.
* **Inventory Management:** Collect, hold, and use items to progress through story puzzles.
* **Dynamic Scoring:** Automatically tracks visited areas and completed puzzles to calculate your overall score.
* **Custom Command Parsing:** Supports standard navigation along with custom context-based actions to interact with environment features and solve puzzles.
